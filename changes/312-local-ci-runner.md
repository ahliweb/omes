Added scripts/ci-local.sh, a local runner that reproduces every GitHub Actions job without GitHub Actions: the fast profile runs each lint.yml job (ShellCheck, shfmt, bats, gitleaks, yamllint, actionlint, supply-chain, link, contract, architecture, Control Center data and change-fragment checks) with the same command and the same blocking-versus-advisory semantics as the workflow YAML, and --profile full adds the compatibility.yml container matrix; every job ends as pass, fail, advisory_fail or skipped, a skipped blocking job makes the whole run incomplete (exit 3) and is never counted as a pass, the tests/run.sh job runs as a non-root uid like the GitHub runner, a workflow-sync check fails when a workflow job has no local counterpart, an optional OMES_CI_REGISTRY_MIRROR keeps digest-pinned images verified through a Docker Hub mirror, proxy variables and an optional extra CA bundle (OMES_CI_EXTRA_CA_FILE) reach containers without any proxy URL being printed, a --json summary is available for tooling, and an opt-in pre-push hook can be installed with --install-hook. The GitHub Actions workflows remain the merge gate; see docs/ci.md section 10.
