Added `omes health budget [--json] [--profile-home PATH]`, a read-only report of the configured Hermes run-budget limits that reads `agent.max_turns`, `agent.run_budget_seconds`, `agent.loop_caps.max_subagents` and `agent.loop_caps.max_web_searches` through the shared allowlisted `hermes config get <key> --json` reader (never `--raw`, no Hermes files or databases, and `hermes usage` and `hermes insights` are never run), warns when `agent.max_turns` or `agent.run_budget_seconds` is an explicit null (unlimited), distinguishes an explicit null from an absent or unreadable key (an absent or unreadable required key makes the status unknown, exit 7, and unknown is never ok), always reports token, spend and cost usage as unknown with no source and no confidence because no supported Hermes interface exposes them (never zero), reports host cgroup limits as not collected, and documents the budget and resource governance model (AWCMS decides policy, Hermes and infrastructure enforce, unknown usage is not zero, emergency stop is scoped and not a global OMES kill) in docs/multi-agent-control-patterns.md section 4.1; OMES meters nothing, enforces no spend ceiling and routes no model (ADR-0029, ADR-0032 rule 8, epic #269).
